PHISHGUARD MOBILE — GITHUB PAGES EDITION

FILES
- index.html: responsive mobile app and URL heuristic checker
- manifest.json: lets supported browsers install it as an app
- sw.js: caches the app for offline use after first visit
- icon.svg, icon-192.png, icon-512.png: app icons

PUBLISH ON GITHUB
1. Extract this ZIP.
2. Upload ALL FOUR app files (index.html, manifest.json, sw.js, icon.svg) into the ROOT of your GitHub repository.
3. If GitHub asks, replace the existing index.html.
4. Open repository Settings > Pages.
5. Choose Deploy from a branch > main > /(root), then Save.
6. Wait for deployment to finish and open your GitHub Pages URL.

INSTALL ON ANDROID
1. Open the published HTTPS GitHub Pages website in Chrome.
2. Open Chrome's ⋮ menu.
3. Tap "Install app" or "Add to Home screen" (wording varies).
4. Confirm. PhishGuard will appear on your home screen.

IMPORTANT
This is an offline educational heuristic demo, not a real-time reputation service.
It does not visit, submit, or test the target URL. It may miss dangerous links or flag harmless ones.
Never enter passwords or personal details on a suspicious site.
